## Validate and manage identity documents

A free and open-source platform written in JavaScript to issue and manage easily-verified identity documents protected with asymmetric cryptography.

* Supports all [ICAO Doc 9303][icao9303] physical documents
* Integrated visual digital seal (<abbr>VDS</abbr>) support for all documents
* Completely-offline validation using cryptography
* [REUSE-compliant][reuse] open-source licensing

[icao9303]: https://www.icao.int/publications/doc-series/doc-9303
[reuse]: https://reuse.software/
